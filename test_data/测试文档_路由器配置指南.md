# H3C ER2100 企业级路由器配置指南

> 文档版本：V1.0 | 适用型号：ER2100 | 更新日期：2025-01

## 一、产品概述

H3C ER2100 是一款面向中小企业的千兆路由器，支持多WAN负载均衡、智能带宽管理、VPN隧道等企业级功能。

### 1.1 主要特性

- 2个千兆WAN口 + 3个千兆LAN口
- 支持PPPoE/DHCP/静态IP三种上网方式
- 内置防火墙，支持ACL访问控制
- 支持IPSec/L2TP VPN
- 最大并发连接数：50000

### 1.2 硬件规格

| 项目 | 参数 |
|------|------|
| CPU | 双核 1.2GHz |
| 内存 | 512MB DDR3 |
| 闪存 | 128MB |
| 功耗 | < 15W |
| 工作温度 | 0°C ~ 40°C |

## 二、快速配置

### 2.1 登录管理界面

1. 将电脑通过网线连接到路由器的 LAN 口
2. 设置电脑 IP 为自动获取（DHCP）
3. 浏览器访问路由器管理页 `http://tplogin.cn`
4. 默认用户名/密码：`admin` / `admin`

### 2.2 WAN口配置

**PPPoE拨号模式：**
1. 进入「网络设置」→「WAN口设置」
2. 连接类型选择「PPPoE」
3. 输入运营商提供的账号和密码
4. 点击「保存并应用」

**DHCP自动获取模式：**
1. 连接类型选择「DHCP」
2. 可选：设置手动DNS服务器
3. 点击「保存并应用」

### 2.3 无线网络配置

1. 进入「无线设置」→「基本设置」
2. 开启无线功能
3. 设置 SSID（网络名称），建议使用英文
4. 安全模式选择「WPA2-PSK」
5. 设置无线密码（至少8位，建议包含字母、数字和符号）

## 三、高级功能

### 3.1 带宽管理

ER2100 支持基于IP的带宽限速和智能QoS：

- **IP限速**：对单个IP地址设置上下行带宽上限
- **智能QoS**：自动识别应用类型（视频/游戏/下载），动态分配带宽
- **时间段控制**：可针对不同时间段设置不同的带宽策略

配置路径：「高级设置」→「带宽管理」

### 3.2 VPN配置

**IPSec VPN（站点到站点）：**

1. 进入「VPN」→「IPSec」
2. 点击「添加」
3. 配置参数：
   - 对端网关地址：远端路由器的公网IP
   - 预共享密钥：两端保持一致
   - 本端子网：本地局域网网段
   - 远端子网：对端局域网网段
4. 保存并启用隧道

### 3.3 端口映射

1. 进入「高级设置」→「端口映射」
2. 点击「添加规则」
3. 设置：
   - 协议类型：TCP/UDP
   - 外部端口：公网访问端口
   - 内部IP：内网服务器地址
   - 内部端口：服务器实际监听端口
4. 保存设置

## 四、常见问题排查

### 4.1 无法上网

1. 检查WAN口状态灯是否正常
2. 确认运营商线路正常（可直连电脑测试）
3. 查看「系统状态」→「WAN口状态」获取IP
4. 尝试修改MTU值（默认1500，可调至1492或1480）

### 4.2 无线信号弱

1. 调整路由器位置，避免金属遮挡
2. 更换信道（建议1/6/11）
3. 检查天线是否拧紧
4. 如仍不理想，考虑增加AP扩展覆盖

### 4.3 端口映射不生效

1. 确认被映射服务器防火墙已放行对应端口
2. 检查运营商是否封禁了该端口（如80/443/25等）
3. 尝试更换外部端口号
4. 查看「系统日志」排查连接记录

## 五、维护建议

- 定期检查固件更新：「系统管理」→「固件升级」
- 每月重启一次路由器以清理缓存
- 备份配置文件：「系统管理」→「配置备份」
- 修改默认管理员密码，增强安全性
